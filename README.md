# ReelsFactory — AI Instagram Reels Automation

**Portfolio showcase · selected real source code**

A local Python + React/Remotion workflow for creating English-language science Reels with procedural scene animations, TTS narration, timed subtitles, validation and an Instagram publishing queue.

## Pipeline
Topic → script/facts → voiceover → storyboard → React/SVG animations → Remotion render → MP4 checks → publication queue.

## Technical work
- Python CLI automation and structured generation stages
- Scene-aware motion graphics and subtitle synchronization
- 1080×1920 vertical video at 30 FPS; target length 20–40 seconds
- FFmpeg/ffprobe technical video validation
- Source-supported claim handling; unconfirmed claims are not treated as independently verified
- Instagram publishing integration with a queue and safety checks

## Code sample
[Caption generator — actual project code](examples/captions.py). It filters source-supported claims and creates topical captions/hashtags.

## Technologies
Python, JavaScript/TypeScript, React, SVG, Remotion, FFmpeg, TTS, SQLite, Meta Instagram API.

## Scope
This is a **portfolio excerpt**, not a runnable full application. Tokens, account configuration, and the full private repository are excluded. No live app or demo URL is claimed here.

## Notes
Scientific claims are subject to a basic source-based workflow; this is not an independent fact-checking service.
